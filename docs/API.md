# HTTP API

All writes (POST, PUT, DELETE) need the `X-CSRF-Token` header (value from `GET /api/csrf-token`, which also sets the `gc_csrf` cookie) and a signed-in session cookie, except sign-in, sign-up and password-reset routes. Responses are JSON.
